# Тыква в бассейне (Tykva v Basseyne)

First-person 3D pool escape game, originally created in ChatGPT Sites.

## Deployment target

- GitHub repository: `IvanBoyko/tykva-v-basseyne`
- Production branch: `main`
- Netlify team: `Softmill`
- Existing Netlify project: [tykva-v-basseyne](https://app.netlify.com/projects/tykva-v-basseyne)
- Intended live URL: https://tykva-v-basseyne.netlify.app

## Migration status

The GitHub repository and Netlify project exist. **Original game source files have not yet been imported.** The source must be exported from the original ChatGPT Site before deploying, to preserve first-person navigation, mobile controls, platforms, and the monster.

Once the original source is imported, add the appropriate Netlify build configuration for that actual source project, connect this GitHub repository in Netlify under **Project configuration → Developer settings → Continuous deployment → Repository**, and select `main`.

> This README is migration scaffolding, not a playable build.
